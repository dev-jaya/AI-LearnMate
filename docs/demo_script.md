# 5-minute hackathon demo script

1. Open AI LearnMate and enter a learner name.
2. Explain that the dashboard starts with no mastery assumptions.
3. Choose Java or Python and generate Adaptive MCQs.
4. Answer questions, intentionally make one or two mistakes.
5. Submit and show the updated score.
6. Explain that the backend stores the attempt and the recommendation engine ranks weak topics.
7. Repeat the quiz to demonstrate the adaptive difficulty change.
8. Explain the optional LLM integration: the demo works without an API key, while an institution can connect an approved LLM provider.
9. Show `/docs` to demonstrate the backend API contract.
10. Close with privacy, human review and scalability safeguards.
