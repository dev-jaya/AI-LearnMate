# 5-minute hackathon demo script

1. Open AI LearnMate and enter a learner name.
2. Explain that the dashboard starts with no mastery assumptions.
3. Choose Java or Python and generate Adaptive MCQs.
4. Answer questions, intentionally make one or two mistakes.
5. Submit and show the updated score.
6. Explain that the backend stores the attempt and uses it to guide later difficulty.
7. Repeat practice to demonstrate the adaptive difficulty change.
8. Upload a PDF/DOCX/PPTX study document and generate source-grounded MCQs from it.
9. Open the AI LearnMate Assistant and ask a normal doubt, a code/debugging question, or a follow-up question. Mention that Gemini is the single server-side AI provider.
10. Show `/docs` to demonstrate the backend API contract.
11. Close with privacy, human review for high-stakes assessment, and the production database scalability note.
